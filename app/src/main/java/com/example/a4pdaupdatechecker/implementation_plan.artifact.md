# Исправление вложенности папок и улучшение взаимодействий

## Цель проекта
1. Устранить визуальные баги, при которых папки могли оказываться внутри самих себя или других папок.
2. Отключить долгое нажатие (редактирование) для обычных ссылок, оставив его только для папок.
3. Реализовать автоматическое создание папок при добавлении приложений, если указанная папка еще не существует.
4. Исправить "глюк" интерфейса при переходе от удержания папки к её открытию.

## План верификации
1. **Проверка вложенности**: Создать папку, зайти в неё и попробовать объединить два приложения в новую папку. Новая папка должна появиться в главном списке, а не внутри текущей.
2. **Проверка долгого нажатия**:
    - Нажать и удерживать папку — должно открыться окно переименования.
    - Нажать и удерживать приложение — ничего не должно происходить (кроме возможности начать перетаскивание).
3. **Проверка авто-создания папок**: Добавить новое приложение, в поле "папка" ввести новое имя. Убедиться, что папка создалась и приложение в ней.
4. **Проверка визуального бага**: Несколько раз быстро удержать и отпустить папку, зайти в неё и выйти. Проверить, не накладываются ли карточки друг на друга.
